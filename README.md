## 一、網站架構專案報告

> 以下照錄 [docs/AI教科書網站架構_專案報告.docx](docs/AI教科書網站架構_專案報告.docx) 全文，由 docx 轉為 Markdown，文字未修改。

### 決策摘要

網站是一個可放多個單元的靜態教科書平台，以節次為主選單，學生版與教師版從同一份內容分開輸出；「干涉與繞射」是第一個單元。以下九項是訪談中確認的決定。

| **\#** | **議題** | **決定**                                                                                                 |
|--------|----------|----------------------------------------------------------------------------------------------------------|
| 1      | 範圍     | 多單元平台；干涉與繞射為第一個單元，網站外框與單元內容分離                                               |
| 2      | 使用者   | 同一網站分學生模式（學生代碼，不需帳號）與教師模式                                                       |
| 3      | 頁面組織 | 以節次為主選單；每節依「預測 → 觀察 → 解釋 → 統整」嵌入各要素                                            |
| 4      | 學習單   | 網頁作答為主（勾選、短答、畫板），同一份題目自動產生列印版（學生版／教師版）；預測題送出後才揭示觀察素材 |
| 5      | AI 追問  | 第一版做固定的 L1 → L2 → L3 分層提示，介面與紀錄格式照 08，預留日後換成 AI 追問                          |
| 6      | 評量計分 | 選擇、是非、配對自動計分；開放題由教師依三級規準評分；雙向細目表由題目標籤自動產生                       |
| 7      | 素材     | 素材庫沿用 07A 欄位，每項標「實拍／模型／示意」並自動顯示授權；模擬附離線截圖                            |
| 8      | 架設     | 靜態網站（如 GitHub Pages），輸出公開學生版與不公開教師版兩份                                            |
| 9      | 作答回收 | 學生下載紀錄檔交給老師；教師版「匯入作答」頁彙整、批改、匯出 CSV                                         |

### 網站整體結構

平台層只管單元清單與模式；每個單元有相同的頁面樹。標「教師版」的頁面只出現在教師版網站。

- 平台首頁：單元清單（依領域、年級篩選）
  - 單元首頁（例：干涉與繞射）
    - 單元總覽：核心結論、先備知識、內容範圍、學習路徑（繩波 → 水波 → 雙狹縫 → 單狹縫與薄膜 → 波動性論證）
    - 前測
    - 第 1 節　波的疊加與水波干涉（含隨堂測驗）
    - 第 2 節　光的雙狹縫干涉（含隨堂測驗）
    - 第 3 節　光的繞射與生活應用（含隨堂測驗）
    - 後測
    - 延伸學習：高中量化、大一波動光學
    - 素材庫：依節次與「實拍／模型／示意」篩選
    - 單元教學設計（教師版）：教案、雙向細目表、學習困難速查、交付檢核
    - 匯入作答與批改（教師版）
    - 列印中心：學習單學生版／教師版

每個節次頁在教師版可切到「投影模式」：大字、一次一個步驟，照「先預測再揭圖」逐步揭示。

### 作答紀錄流程與技術架構

網站沒有伺服器：作答存在學生瀏覽器，以檔案交給老師，由教師版匯入批改。

1.  學生輸入學生代碼進入學生版，作答自動暫存於瀏覽器，重新整理可續作。
2.  每節結束按「下載本節紀錄」，得到以學生代碼命名的 JSON 檔。
3.  學生把檔案交到 Google Classroom 或雲端資料夾；共用設備按「清除本機紀錄」。
4.  教師在教師版「匯入作答」頁一次拖入全班檔案，網站整理成表格。
5.  客觀題自動算分；開放題依三級規準（達成／發展中／待支持）勾選。
6.  匯出 CSV 成績表。

**紀錄欄位**（依 08）：學生代碼、單元與節次、題號、初稿與修訂稿、作圖、必要操作紀錄（如模擬播放、選 B／D）、提示使用歷程（用到第幾層）、轉教師標記、時間、教材版本。提示使用歷程的格式與日後 AI 對話相同，切換時不需改紀錄格式。

**技術架構**

- 靜態網站產生器讀取 units/ 內容檔，輸出兩份網站：學生版（公開網址）、教師版（不公開網址或下載本機開啟）。
- 架設在 GitHub Pages 一類的免費靜態空間；正文、圖片、學習單可離線使用。
- 互動模擬以嵌入方式放入節次頁；07A 指出它們依賴外部套件（Tailwind、Three.js、MathJax），完全離線需先把套件打包進網站。
- 列印版學習單由同一份題目輸出為可列印頁面（學生版／教師版）。
